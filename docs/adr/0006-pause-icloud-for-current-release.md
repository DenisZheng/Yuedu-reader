# 当前版本暂时停用iCloud，保留本地能力与WebDAV

2026-11-15，用户通过轻松签安装3.0（4）后，在首屏前发生CloudKit异常。日志主程序UUID与云端IPA一致；具体签名权限缺失项未由签名后IPA确认，但现有初始化在未授权签名下会尝试创建云容器。用户先选择侧载包不使用iCloud，随后明确要求本版先取消该功能。

本版隐藏iCloud入口、停止启动及前后台自动调用、不申请CloudKit权限，并将配置状态设为不可用；保留iCloud实现与现有本地／远端数据以便将来恢复，WebDAV及本地阅读不变。这暂时覆盖ADR-0004和RSS方案中的保留iCloud约定，不授权删除数据或改签名账号。App显示名确认为`LegadoPro`，Bundle ID、共享数据空间和URL scheme保持不变。

恢复iCloud前必须重新确认自有App ID、容器与签名授权，并完成无权限签名下仍能本地启动的设备回归；不能仅凭证书有效期或归档成功恢复功能。当前改动是否消除用户闪退仍须新云端IPA自签后的手机启动复验。
