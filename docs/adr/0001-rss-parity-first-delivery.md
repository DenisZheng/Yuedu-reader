# 首期以 RSS 行为闭环为交付范围

首期对齐 Legado 的 RSS 导入、内容获取、分类与分页、规则网页/媒体展示及阅读状态闭环，不同时铺开整个阅读器的功能差异。书源和其他模块作为后续范围保留，Dict 与 AutoTask/Cron 暂按原方案排除；这样可以先用现有真实订阅源完成可观察的行为验收，避免跨多个系统同时改变而无法定位回归。

验收采用去敏固定输入测试，加独立测试数据环境中的少量代表源联网验证；不使用个人账号，不自动执行购买、发布或外部导入等动作。全包执行导入与字段检查，按文本、图片、HTML 视频、脚本、登录和分页等类别选择代表源实测；结果逐项列出未验证与受限项，不将样本测试扩大解释为全包可用率。首期恢复独立订阅入口；当前播放器不支持的格式或 DRM 明确提示，不增加播放器依赖来强行追求全覆盖。
