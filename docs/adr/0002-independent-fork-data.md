# 首次交付使用独立 Fork 数据空间

> 部分约束已由 [ADR-0004](0004-remove-google-and-billing.md) 替代：保留 iCloud/WebDAV，并移除收费体系。独立数据空间的选择不变。

首次交付面向独立 Fork 的全新安装，不承诺接续原版 Yuedu 的账号、云端数据或历史阅读状态，也不覆盖原版数据。这使首期能够确立正确的来源、分类、条目和媒体身份，而不必同时迁移原版已经存在歧义的状态；但 Fork 自身发布后的升级仍必须保持数据兼容。

首期本地独立，不接自建云服务，RSS 不依赖原版账号、Pro 或云端；仅隔离构建、启动和 RSS 所必需的原版服务依赖，不顺带重构其他功能。此决策不授权删除本机既有数据、复用原版云端凭据，或取消与 RSS 无关功能的权限控制。
