# 规则网页按 Android 源配置执行，保留平台与权限边界

为使 Legado 的网页型订阅源可用，首期按 Android 基准的源配置执行网页、脚本、iframe 和媒体行为，而不是统一将其当作普通 Feed 文章清理。普通 Feed 保持安全文章路径；导入确认应说明规则可运行脚本和访问网站，源声明的 enableJs、注入时机、基址和跳转规则都属于可验证的行为合同。

这不赋予网页任意系统权限，不复制 Android/Java 的文件或系统访问能力。源配置、解析脚本、网页桥接各有明确身份和授权，禁止跨源读取状态和把私有请求头转发到无关目标；测试不自动执行购买、发布或外部导入。无法支持的协议/格式/运行时能力明确列为受限，不以“打开原文”或静默 no-op 冒充兼容；首期不引入新播放器依赖。

选择依据：真实 RSS 包全部为网页型，但含脚本和媒体内容；只放宽静态 HTML 标签不足以恢复其功能。具体媒体资源传输方式必须经 PoC 验证后确定，本决策不预先选定自定义 URL scheme 或 loopback 代理。
