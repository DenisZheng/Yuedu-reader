# 移除 Google 与收费体系，保留 iCloud 和 WebDAV

用户在 S0 发现 Google/Firebase 二进制下载阻碍后明确调整产品范围：移除 Google/Firebase 相关账号、云端同步、反馈/诊断上报依赖，同时移除 StoreKit 购买、会员校验和 Pro 功能限制；保留 Apple 原生 iCloud 与 WebDAV。已有功能在 Fork 中本地可用，但 AI 等外部服务仍需用户自己的配置，不能借用原版账号或服务凭据。

此决策替代 ADR-0002 中“首期仅本地、不接云服务”及“不调整非 RSS 收费控制”的部分约束；独立 Fork、全新数据空间、不覆盖原版数据和不复用原版云端身份仍然有效。iCloud 使用 Fork 自己的容器/签名，不可用时不阻止本地阅读；本地日志与 RSS 本地通知保留。Q12–Q13 已确认：WebDAV 对齐 Android 的分类选择、备份包与恢复机制，先保证 Fork 自身恢复；首期不做 Android 备份文件互通，跨端迁移留后续。现有书库备份保留，RSS 配置/状态在稳定身份模型完成后接入；敏感运行数据默认排除，正文及音视频缓存不默认打包。

移除 SDK 是已确认的产品选择，不是假装修复网络 TLS；需要完整处理调用方、构建依赖、资源和测试，不用伪造 Firebase 配置或空实现掩盖仍在调用的服务。原网络下载失败保留在验证记录中，不记为已恢复。
