## 4. 仍需单独处理

- **S8／发布门槛尚未全部接受**：当前版本的真机、iPad、最低 iOS 17、VoiceOver、真实账号／受限站点和所需真实 WebDAV 场景，必须逐项保留或补充目标版本证据；不能用模拟器结果代替。
- **段评只读**：发帖、点赞、删除等写动作未纳入本批；歌词／弹幕是有限列表与时间定位，不是全部格式、实时歌词高亮或滚动弹幕引擎。
- **原 Files 文件夹导航限制仍在**：从 Files 根层直接选文件是用户接受的验收绕行，不是故障已修复。
- **其他全项目差异未在本轮完成**：完整替换作用域、Android 整包迁移／跨端进度、完整分类与自动备份、在线书导出／正文编辑、多分组／换源细项、有限 Java/API 缺口、Web/MCP 和 UMD，按需要另立批次；候选及历史依据见 [差距审计](current-feature-parity-audit.md)。
- **视频播放与快进问题分开**：用户已确认真实视频可播放；偶发快进异常仍是单列的小 Bug，不重新报为缺少视频功能。
- **产品边界不变**：Google/Firebase 和收费限制不恢复；iCloud 按 [ADR-0006](../adr/0006-pause-icloud-for-current-release.md) 暂停，保留实现及数据，WebDAV 保留。Dict、AutoTask/Cron 不做，不增加第二套播放器或无界网页代理。
