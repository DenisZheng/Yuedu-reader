用户确认首批只做：正则语义、书源配置保真、文件型书源、规则包订阅更新。视频已能播放，偶发快进问题不在本批；不恢复收费、Google/Firebase、iCloud，不实现 Dict/Cron、Android 迁移、跨端同步、Web/MCP 或 UMD。

- Android 基准：`330e606c4d57e08adc056ff8ab7a4132c784da9a`，不改基准仓库。
- 原 main 的导入/日志修复、审计文档和原始源包保持原处，不混入本批业务提交。
- 自动测试通过后仍等待用户人工确认，才合入 main；不自动 push、发布、安装手机或清数据。

## 完成标准

### 1. 正则

先用生产 RegexCache 复现 possessive/atomic 被改写后的匹配差异，再保留平台实际支持的原语义。覆盖提取/替换和已有 Java 特有字符类兼容，不通过修改旧期望让测试假通过。

### 2. 书源配置保真

导入→确认/编辑→保存→重载→导出保留顶层及嵌套未知 JSON 信息。已知字段编辑以当前模型为准，保留的字段不被误执行；缺少执行能力的协议给出明确提示，不把保存 mainJs 等字段记为这些功能已实现。更新保留本地身份/设置，并能识别只有扩展字段改变的配置修订。

### 3. 文件型书源

详情在同一规则上下文提取 downloadUrls，保留列表/缓存/重载数据；type=3进入下载选择而不是正文目录。用户选择后沿共享 AnalyzeUrl/请求/Cookie/限流链下载，复用 LocalBookImportService。空链接、失败、取消、过期源配置不得假成功或写入书架；固定本地响应验证真正导入可读文件，不访问原包公网源。

### 4. 规则包订阅

书源/RSS/替换规则包的地址、自动更新开关、小时更新间隔、静默/待确认更新和状态持久化。复用现有包下载/解析/比较/导入，保存配置与抓内容分开。到期检查在前台执行，不承诺后台常驻。失败不推进成功时间，删除/修改/取消拒绝旧结果；不变不写，更新保留用户本地设置。Android自动路径不消费的js/showRule仅保留，不猜测执行。

## 验证方式

先建立隔离回归并记录有效RED，后逐项GREEN。使用动态解析的Xcode/目标及既有scripts/xctest.sh串行测试，不clean或用新DerivedData绕过问题；新增功能测试用独立store和自建输入，不覆盖用户数据。

自动验收包含：新功能行为测试、相关原路径回归、五语言本地化、文档链接/格式和git diff --check。UI用原生Form/List/Picker/NavigationLink及DS tokens，推入/模态标题inline，提供Preview、空/加载/错误/取消状态和可访问标签。

真机、最低iOS17、真实服务及用户人工操作未执行时明确记录，不冒充通过。最终人工确认项目：文件型书源选择→下载→打开；规则包新增→检查→确认/静默更新→重启恢复；取消及失败提示，最大字号/VoiceOver基本可达。

### 已实施的行为

- 正则优先编译原表达式，实际不支持时才用兼容转换；提取、替换、TXT目录和共享缓存继续走原有路径。
- 书源未知顶层与六类规则内的JSON值保留；双重编码规则也覆盖，坏规则拒绝，不变更已知字段的权威来源。保存的是JSON语义，不保证原字节、空白或键顺序一致。
- 文件型书源从`ruleBookInfo.downloadUrls`提取下载项；下载选择进入独立详情，复用共享请求执行器与本地导入。64 MiB预算、原始字节、POST/请求变量/头部、取消和源失效均覆盖。加载任务有代次保护；源在本地解析期间失效时只撤销本次新建书籍ID，不碰既有书。
- 配置包订阅新增、编辑、删除与确认入口在「设置→规则包订阅」。持久文件`rule_subscriptions_v1.json`使用格式1，保存尝试时间、成功时间及作者版本；待确认的包与错误提示只保存在内存，重启后需重新检查。
- 书源与RSS更新保留本地身份、名称、分组及启用状态；替换规则保留本地ID、名称、启用状态和顺序，数字作者ID另外映射。目标owner真正落盘后才记成功，写入失败保留待写快照供重试。
- 元数据读写、JSON比较及大列表确认摘要在后台；前台激活串行检查到期项，离开前台取消在途检查，不新建后台常驻任务。
- 五语言补齐46个文案key；新页面使用原生Form/List/Picker、DS tokens和inline标题，提供页面Preview。

### 已知限制

- 助手自动验证使用自建数据、隔离store与本机响应；用户另在专用模拟器按预置实源／本机更新包步骤确认全部OK。助手未替用户访问源站、使用个人账号、自动登录、安装手机或授予权限。
- 用户反馈覆盖人工指南中的文件下载→书架→阅读、配置更新、取消／失败、重启与显示检查；没有逐项书名、URL或截图的独立报告，不据此宣称所有文件源／格式都已实测。iPad、真机、最低iOS17和VoiceOver专项测试没有新增独立确认。
- 配置包每次最多8 MiB／10,000项，订阅最多128条，小时间隔范围0–8,760；普通包支持书源、RSS与替换规则。替换包需要稳定数字或UUID的ID；当前未支持的标题／来源作用域、排除范围及非默认超时明确拒绝，不降级丢字段后提示成功。
- Android自动检查不执行的`js`、`showRule`、`sourceUrl`仅保存。本轮没有补齐这些字段关联的全部人工网页能力，也不宣称替换规则执行语义已全面对齐。
- 订阅文件只实现本地保存与重载；本轮不扩展WebDAV备份清单、Android迁移或跨端同步。
- 书源原有本地写入时钟策略未改，订阅另记作者时钟；不是源包的逐字节保真。已经确认并提交的配置变更不会因取消订阅被反向删除。
- 测试产物在未跟踪的`.artifacts/`，不加入业务提交。原main的运行时／导入改动先独立提交，再与本批整合；整合回归、日志隐私gate与五语言检查已实际通过，不把合并前的单分支结果冒充整合结果。
